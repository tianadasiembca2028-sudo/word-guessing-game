# Word Guessing Game

## About the Project

Word Guessing Game is a Python-based console game where the player
tries to guess a randomly selected word within a limited number of
attempts.

## Features

- Random word selection
- User-friendly console interface
- Limited attempts
- Correct and incorrect guess tracking
- Win and lose conditions

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python wordguess.py
